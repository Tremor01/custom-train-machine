# Мастерская распознавания

Веб-приложение для обучения классификатора изображений на Node.js сервере и распознавания с камеры в браузере или на сервере. Использует TensorFlow.js и MobileNetV2.

## Запуск

Установите Node.js 20 или новее. В терминале откройте папку проекта и выполните:

```sh
npm install
npm run dev
```

Откройте адрес, показанный в терминале (обычно http://127.0.0.1:5173), разрешите доступ к камере и введите токен API. Для production задайте `APP_TOKEN` длиной не менее 24 символов, соберите UI (`npm run build`) и запустите `NODE_ENV=production npm run server`; сервер раздаёт собранный `dist`. Полная инструкция есть в [docs/server-deployment.md](docs/server-deployment.md). Базовая MobileNet хранится в `public/models/mobilenet`; если файлы модели удалены, восстановите их командой `npm run download-model`.

Обучение всегда выполняется на сервере. Режим камеры «На устройстве» оставляет поток локальным и выполняет предсказание в браузере; режим «На сервере» отправляет сжатые кадры по одному для обработки сервером.

## Использование

Создайте минимум два класса, добавьте примеры и нажмите «Обучить модель». Настройки классов сохраняются в локальный JSON-проект вместе с примерами. После изменения примеров выполните серверное обучение повторно. Модели хранятся на VPS в `DATA_DIR`.

Для автоматического сбора кадров нажмите «Собирать с камеры» у нужного класса, меняйте положение объекта и нажмите «Остановить сбор». Максимум примеров на класс задаётся над списком классов; по умолчанию — 200. Лимит действует на сбор с камеры и загрузку изображений, он сохраняется в проекте. При обучении примерно 20% примеров каждого класса откладываются для проверки; графики показывают метрики обучения и проверки, а после обучения отображается матрица ошибок. Для класса с одним примером проверить качество нельзя. Кнопка ⛶ увеличивает камеру и показывает эффекты поверх видео; кнопка × возвращает обычный размер. Распознавание можно остановить отдельно, а кнопка камеры выключает видеопоток и освобождает камеру. Индикатор показывает прогресс чтения файлов базовой модели и отдельный этап её подготовки.

Звук проигрывается при переходе к уверенному классу; некоторые браузеры могут требовать взаимодействия со страницей для воспроизведения звука.

### Игра «Камень, ножницы, бумага»

После обучения модели назначьте три разных класса ходам «Камень», «Ножницы» и «Бумага». Нажмите «Начать раунд» и удерживайте нужный жест перед камерой после обратного отсчёта. Компьютер выбирает ход случайно перед раундом и показывает его одновременно с распознанным жестом. Порог уверенности общий с вкладкой обучения и по умолчанию равен 75%. Если уверенность ниже порога, приложение продолжает распознавание автоматически — жест можно поменять, когда удобно. После результата можно начать следующий раунд. Изменение классов или модели и остановка распознавания отменяют активный раунд.

## Проверки

`npm test` — тесты логики; `npm run build` — сборка приложения.
